# LSPosed-Caffeinate

Модуль LSPosed / Android-приложение, которое не даёт устройству уходить в сон.

## Режимы

- **Не выключать дисплей**: экран остаётся включённым.
- **Не блокировать дисплей**: экран может погаснуть, но устройство не блокируется.
- **Не выключать и не блокировать**: оба режима одновременно.

## Возможности

- Работа по таймеру с автоматическим отключением по истечении времени.
- Плитка в шторке быстрых настроек: включение и переключение пресетов одним нажатием.
- Отображение оставшегося времени таймера прямо на плитке, рядом с иконкой.
- Пользовательские пресеты времени (например, 5 мин, 15 мин, 1 ч, бесконечно).
- Экран настроек для выбора режима и управления пресетами.

## Требования

- Android с root-доступом и установленным [LSPosed](https://github.com/LSPosed/LSPosed).

Проект в начальной стадии разработки.
