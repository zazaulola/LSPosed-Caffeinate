# LSPosed-Caffeinate

Модуль LSPosed / Android-приложение, которое не даёт устройству уходить в сон.

## Режимы

- **Не выключать дисплей**: экран остаётся включённым.
- **Не блокировать дисплей**: экран может погаснуть, но устройство не блокируется.
- **Не выключать и не блокировать**: оба режима одновременно.

## Возможности

- Работа по таймеру с автоматическим отключением по истечении времени.
- Плитка в шторке быстрых настроек: включение и переключение пресетов одним нажатием.
- Отображение оставшегося времени таймера прямо на плитке, рядом с иконкой.
- Пользовательские пресеты времени (например, 5 мин, 15 мин, 1 ч, бесконечно).
- Экран настроек для выбора режима и управления пресетами.

## Требования

- Android 8.0+ (minSdk 26). Плитка с подписью под названием: Android 10+.
- Для режима «не блокировать» при блокировке с PIN/паролем/отпечатком: root и [LSPosed](https://github.com/LSPosed/LSPosed)
  с включённым модулем и областью «Системный интерфейс» (`com.android.systemui`).
- Режим «не выключать дисплей» работает и без root.

## Как это работает

| Режим | Механизм |
|---|---|
| Не выключать дисплей | `SCREEN_BRIGHT_WAKE_LOCK` в foreground-сервисе |
| Не блокировать дисплей | Хук `KeyguardViewMediator.doKeyguardLocked()` в SystemUI: пока таймер идёт, экран блокировки не показывается. Без LSPosed: `KeyguardLock.disableKeyguard()` (только для блокировки свайпом) |
| Оба | Оба механизма сразу |

Во всех режимах держится `PARTIAL_WAKE_LOCK`, чтобы таймер срабатывал вовремя.
Когда таймер истекает при погашенном экране, хук сразу блокирует устройство.

Приложение передаёт состояние хуку широковещательным сообщением, защищённым
signature-разрешением: другие приложения не могут отключить блокировку через модуль.

### Плитка

- Нажатие: выкл → первый пресет → второй → … → выкл.
- Пока таймер работает, вместо названия на плитке оставшееся время (`14:59`, `∞`), под ним режим.
- Долгое нажатие открывает настройки.

## Установка

1. Скачайте APK из артефактов сборки GitHub Actions (или соберите сами) и установите.
2. В LSPosed Manager включите модуль, отметьте «Системный интерфейс» и само приложение.
3. Перезапустите SystemUI (или устройство).
4. Добавьте плитку Caffeinate в шторку.

## Сборка

```sh
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (platform 35).

## Ограничения

- На прошивках с сильно изменённым SystemUI (например, One UI) класс `KeyguardViewMediator` может
  отличаться; в логе LSPosed будет сообщение `Caffeinate: ... not found`.
- В режиме «не блокировать» блокировка кнопкой питания тоже пропускается, пока таймер идёт.
